# 🎬 MediaSearch App (React + Redux)

MediaSearch is a modern and responsive **media search application** built using **React** and **Redux**.  
It allows users to search for **Photos, Videos, and GIFs**, save their favorite media, and manage a personal collection.

## 🚀 Features

- 🔍 Search media by keywords
- 🖼️ Browse **Photos**, 🎥 **Videos**, and 🎞️ **GIFs**
- ❤️ Save media to personal collection
- 🗑️ Remove individual items from collection
- ❌ Clear entire collection at once
- ⚡ Fast state management using **Redux**
- 🌙 Clean dark-themed UI
- 📱 Fully responsive design

## 🛠️ Tech Stack

- **Frontend:** React.js  
- **State Management:** Redux / Redux Toolkit  
- **Styling:** CSS / Custom UI  
- **API:** Media API (Photos, Videos & GIFs)  
- **Version Control:** Git & GitHub  

---


---

## 🔄 Redux Flow (How it works)

1. User searches for media using the search bar  
2. API request is triggered via Redux action  
3. Media data is stored in Redux store  
4. Components access data using `useSelector`  
5. User can save media to **Collection**  
6. Collection state is managed globally using Redux
